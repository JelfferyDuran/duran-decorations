# Duran Decorations 🎈

Party & event decorations by Kristina Duran — New Jersey.

Balloon arches, themed party styling, weddings, baby showers, graduations, quinceañeras, and custom decor. Bilingual (EN/ES), dark mode, mobile-first.

**Live:** https://jelfferyduran.github.io/duran-decorations/

## Structure
- `index.html` — single-page site (hero, portfolio, how it works, about, FAQ, contact)
- `catalog.json` — portfolio items (add new designs here)
- `assets/` — imagery

## Add a new design
1. Drop the image in `assets/`
2. Add an entry to `catalog.json` (name/name_es, cat/cat_es, img, desc/desc_es, optional tag: best|new|premium)
3. Push — GitHub Pages auto-deploys.
